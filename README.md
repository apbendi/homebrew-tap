# Apbendi Tap

## How do I install these formulae?

`brew install apbendi/tap/<formula>`

Or `brew tap apbendi/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "apbendi/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
